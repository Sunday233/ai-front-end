# object-type-list UI 分析清单

## 来源

- PRD：`docs/prd/object-type-list.md`
- 主设计源：Stitch MCP
- Stitch 项目：`projects/11214155578152749288`
- Stitch screen：`37c4513811cd4dda8f40b5949e97f7ab`，标题 `对象类型列表页-导航同步`
- 补充截图：`docs/ui/对象类型列表页.png`

## 全局样式

- 左侧导航、色彩、字体与工作台保持一致。
- 主内容区背景 `#F5F5F5`，内容表格容器白底。
- 表头背景 `#F4F5F7`，表格行高约 58px，隔行背景接近 `#FAFAFB`。
- 状态 tag：正常为绿色浅底，草稿为蓝色浅底；可见性 tag 为蓝色浅底。

## 布局与元素

1. 面包屑：`返回首页 | 对象类型`。
2. 标题区：`对象类型列表`，右侧数量角标 `39`。
3. 操作区左侧为搜索框，placeholder 为 `请输入类型名称、id或rid进行搜索`，右侧展示 `0 / 50` 与搜索图标。
4. 操作区右侧依次为刷新按钮、设置按钮、蓝色 `+ 创建` 按钮。
5. 表格列顺序：类型名称、状态、可见性、修改时间、操作。
6. 类型名称前有蓝色对象图标；操作列为蓝色文字 `详情`。
7. 分页位于表格右下：`第1/4，共39条`、页码、下一页、每页条数、前往输入框。

## 状态

- default：展示 9 条对象类型数据。
- loading：刷新或搜索时禁用刷新按钮，表格显示加载状态。
- search_empty：搜索无结果时展示空态。
- no_permission：隐藏创建按钮，操作列保留详情。

## 验证检查清单

- 搜索、刷新、创建按钮位置与截图一致。
- 表格列顺序、状态颜色、分页布局与设计稿一致。
- 搜索高亮可见，空状态和加载态可触发。
