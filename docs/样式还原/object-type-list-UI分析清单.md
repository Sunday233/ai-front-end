## 样式规范汇总

- 表头背景 `#F4F5F7`，行分割线 `#F0F1F4`，隔行轻微 `#FAFAFB`。
- 状态「正常」为绿色浅底，状态「草稿」为蓝色浅底；可见性为蓝色浅底。
- 操作文字 `#0B66FD`，无按钮外框。
- 页面内容左内边距约 24px，表格容器左右留白约 16px。
