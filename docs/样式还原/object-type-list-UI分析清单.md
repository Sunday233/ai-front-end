## 二、区域详细分析

### 区域1：导航与标题

- 面包屑：`返回首页 | 对象类型`，灰色辅助文本，当前页带对象类型图标。
- 标题：`对象类型列表`，右侧计数标签 `39`。
- 左侧菜单选中项：`对象类型 39`，浅蓝背景，文字蓝色。
- 页面使用左侧固定导航 + 右侧内容的左右布局。

- 搜索框占位：`请输入类型名称、id或rid进行搜索`，右侧显示 `0 / 50`。

- 刷新、设置为 32x32 浅灰图标按钮；创建按钮约 74x32。

## 六、实现建议

- 页面路由：`/object-types`，页面目录 `src/views/object-type-list/`。
- 表格必须按行级映射实现，不得改变列顺序。
- 搜索高亮只高亮名称、ID、RID 命中片段，避免改变行高。
- 刷新/设置使用图标按钮，保持 32x32 稳定尺寸。
