## 七、实现建议

- 页面路由建议：`/object-types`，页面目录 `src/views/object-type-list/`。
- 表格使用 Ant Design Vue `Table`，分页使用 `Pagination`，搜索使用 `Input`。
- 搜索高亮应只高亮名称、ID、RID 命中片段，避免改变行高。
- 刷新/设置使用图标按钮，保留 32x32 稳定尺寸。
