# workbench UI 分析清单

## 来源

- PRD：`docs/prd/workbench.md`
- 主设计源：Stitch MCP
- Stitch 项目：`projects/11214155578152749288`，标题 `Object Type Design System`
- Stitch screen：`c9d705f09f7544ae938e7b629e605e38`，标题 `工作台-默认状态-导航同步-顶栏高亮`
- 补充截图：`docs/ui/工作台默认状态.png`、`docs/ui/工作台-点击新建按钮.png`

## 全局样式

- 设计基准：1440x900，截图为 1600x807，Stitch screen 为 2560x2048。
- 主色：`#0B66FD`；内容背景：`#F5F5F5`；页面模块白底：`#FFFFFF`；边框：`#D9DCE2`；分割线：`#F0F1F4`。
- 字体：系统默认字体，正文 14px/22px，标题 16px/24px 或 20px/28px。
- 左侧导航固定宽度约 176px，本次实现按 Stitch 设计系统使用 208px，页面最小宽度 1280px 时保持可用。
- 控件圆角以 4px 为主，卡片圆角 6px，间距遵循 8px 网格。

## 布局与元素

1. 左侧导航为白底固定栏，顶部展示 `智能体管理Matrix`，下方空间名 `rrr`。
2. 导航数据资源区包含工作台、对象类型、链接类型、动作类型、对象类型组、智能体管理、数据清理、知识库。
3. 当前工作台菜单浅蓝底高亮；对象类型等菜单右侧展示数量角标。
4. 右侧工作区顶部为面包屑 `返回首页 | 工作台`，右侧有浅色云形装饰背景。
5. 顶部搜索条横向铺满内容区，placeholder 为 `请输入关键词进行搜索`，右侧展示 `0 / 50` 与搜索图标。
6. 搜索条右侧是蓝色 `+ 新建` 按钮；点击后出现下拉面板，包含对象类型、链接类型、动作类型、对象类型组四项。
7. 主内容展示 `最近浏览的对象类型 1` 与 `收藏的对象类型 4` 两个分区。
8. 对象类型卡片为白底，左侧蓝色图标块，标题、实例数、应用次数、描述、底部关联标签与更多操作。
9. 收藏卡片为四列布局，右上角展示黄色收藏星标。
10. 左侧底部固定展示 `已编辑 22 处`，下方有 `放弃` 与蓝色 `保存` 按钮。

## 状态

- 默认态：工作台菜单高亮，展示最近浏览与收藏卡片。
- dropdown_open：新建按钮下方右对齐浮层，白底阴影，顶部小三角指向按钮。
- hover：菜单项、卡片、按钮有轻微背景或阴影变化。
- no_permission：隐藏新建按钮与下拉入口。

## 验证检查清单

- 左侧导航固定且高度撑满视口。
- 工作区背景、白色卡片、搜索条、新建浮层与截图层级一致。
- 卡片文案、数量角标、星标、底部标签和更多按钮完整。
- 新建下拉菜单可触发，并包含四类创建入口。
