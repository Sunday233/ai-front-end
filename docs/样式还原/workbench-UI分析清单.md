## 四、交互状态分析

- 菜单选中：浅蓝背景，文字与图标为主色。
- 新建按钮默认：主色背景；点击后弹出菜单，菜单右上角靠近按钮并有三角指示。
- 新建下拉项：图标 + 主标题 + 灰色描述，垂直列表排列。
- 收藏星标：默认展示黄色星形，表示已收藏。
- 权限隐藏：无新建权限时不渲染「新建」按钮，无管理权限时不渲染管理入口。

## 六、实现建议

- 页面路由：`/workbench`，页面目录 `src/views/workbench/`。
- 左侧导航在当前三页复用，实施时可放入 `src/layout/app-shell/`，也可按组件拆分清单先做候选复用。
- 卡片列表使用响应式 grid，避免固定 4 列导致小屏溢出。
- 新建下拉使用受控浮层状态，确保位置、宽度、阴影和选项顺序一致。
