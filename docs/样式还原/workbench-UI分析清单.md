## 整体布局

- 基准截图尺寸：1600 x 807，本地实现按 1440/1600 宽度响应。
- 页面采用固定左侧导航 + 流体内容区。左侧宽约 176px，白底，右侧内容背景 `--matrix-bg-page`。
- 顶部内容区有浅色科技背景，面包屑位于左上，右上为蓝色「新建」按钮。
- 主内容从顶部搜索栏开始，搜索栏高度约 32px，右侧计数 `0 / 50` 与搜索图标。
- 工作台卡片分为「最近浏览的对象类型」与「收藏的对象类型」，标题旁有浅灰数量标签。

## 样式规范汇总

- 主色：`#0B66FD`，选中/按钮/链接使用。
- 页面背景：`#F5F5F5`，卡片与侧栏背景：`#FFFFFF`。
- 正文：14px / 22px；标题：16px / 24px；辅助文字：12px / 20px。
- 边框：`#D9DCE2`；分割线：`#F0F1F4`；浅蓝选中背景近似 `#E6F4FF`。
