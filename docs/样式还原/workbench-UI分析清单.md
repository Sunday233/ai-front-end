## 七、实现建议

- 页面路由建议：`/workbench`，页面目录 `src/views/workbench/`。
- 左侧导航在当前三页复用，但本仓库首次落地时可先放在页面级组件；第二处真实使用时再抽为 `src/layout` 或 `src/components`。
- 卡片列表使用响应式 grid，避免固定 4 列导致小屏溢出。
- 新建下拉使用 Ant Design Vue `Dropdown` / `Menu`，搜索使用 `Input`。
