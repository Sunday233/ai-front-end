## 整体布局

- 左侧导航与列表页保持一致，当前选中「对象类型 39」。
- 内容区顶部面包屑为 `返回首页 | 对象类型 > 创建对象类型`。
- 页面主体有两个白色大容器：步骤条容器与步骤内容容器。容器圆角约 4px，外部背景 `#F5F5F5`。
- 步骤条横向四段，圆点编号 1-4，当前步骤蓝色，未完成步骤灰色。
- 底部操作按钮固定在内容容器右下区域，次要按钮白底，主按钮蓝底。
