## 全局样式

- 与工作台共用左侧导航、内容背景、顶栏装饰。
- 创建页主体由两个白色面板组成：上方步骤条，下方当前步骤内容。
- 步骤条横向四等分，当前步骤蓝色圆点，已完成步骤蓝色描边，未激活为灰色。
- 操作按钮固定在内容面板右下角，主按钮为 `#0B66FD`。

## 步骤结构

1. 步骤 1 选择数据源：面包屑 `返回首页 | 对象类型 > 创建对象类型`，卡片内展示数据源选项，默认选中 `已有数据集`，右侧有 `+ 选择数据集`，底部按钮 `下一步`。
2. 选择数据集弹窗：标题 `选择数据集`，顶部搜索框和清空按钮，左侧数据集列表，右侧详情区含 `基本信息`、`列信息`、`数据预览` tab，底部 `取消`、`选择`。
3. 步骤 2 元数据配置：居中表单，包含图标、对象类型显示名称、同义词、ID、描述、所在对象组。输入框右侧显示字数。
4. 步骤 3 属性配置：左侧主键和数据集字段，右侧标题键与属性名称映射。字段行包含类型选择、字段名、主键 tag、删除按钮；底部 `上一步`、`下一步`。
5. 步骤 4 动作配置：展示三个可选操作类型卡片，分别为创建测试、修改测试、删除测试；底部 `上一步`、`完成`。

## 状态

- disabled_next：步骤必填项未满足时下一步禁用。
- validation_error：字段错误提示靠近字段展示。
- confirm_primary_key：修改主键时展示确认弹窗。
- submit_success：完成后返回对象类型列表。
- dropdown/open modal：选择数据集、添加对象组、选择用户等弹窗与截图层级一致。

## 验证检查清单

- 四步步骤条顺序、激活态、说明文案一致。
- 表单字段、字数、必填星号、按钮位置完整。
- 属性配置左右两列、字段行、主键 tag 和删除按钮完整。
- 动作配置三张横向大选项卡完整，完成按钮可提交。
