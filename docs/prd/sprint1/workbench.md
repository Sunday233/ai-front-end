# 功能概述
Matrix智能体工作台用于展示当前空间内智能体全部对象类型，支持名称快速检索，可查询查看智能体内对象类型、链接、动作等资源列表，同时支持智能体属性配置、权限管控与内部数据编辑调整，一站式完成智能体日常管理与资源运维。

# 用户角色
- 智能体管理员
- 智能体普通操作人员
- 拥有资源新建权限用户
- 系统管理员
- 产品经理

# 功能步骤
## 1. 工作台菜单列表
1. 进入Matrix智能体工作台页面，自动加载左侧全局导航菜单
2. 顶部查看当前所属空间及智能体名称，快捷进入工作台、智能体探索、分支管理、操作日志
3. 中间区域查看各类数据资源及统计数量，点击对应菜单项跳转至对应资源列表页
4. 拥有管理权限可查看底部智能体管理、数据清理入口，点击进入对应管理页面

## 2. 工作台新建功能
1. 在工作台页面点击顶部【新建】按钮
2. 弹出下拉选择菜单，按需选择创建对象类型、链接、动作
3. 选中对应类型后自动跳转至对应资源创建页面，开始新建流程

# 交互说明
## 一、左侧导航菜单交互
1. 页面布局、菜单层级、文字样式、数量角标样式严格参照Figma设计稿还原
2. 菜单分区规范
    - 顶部区：展示智能体名称 + 快捷操作入口（工作台、智能体探索、分支管理、操作日志）
    - 资源区：展示对象类型、共享属性、链接类型、动作类型、动作类型组，格式统一为「资源名称+统计数量」
    - 管理区：仅有权限用户可见，包含智能体管理、数据清理入口
3. 数量统计规则
    - 统计当前智能体下**全状态**资源总量（草稿、已发布、废弃全部计入）
    - 已通过数据清理彻底删除的数据资源不参与数量统计
4. 点击菜单项直接路由跳转至对应资源列表页面

## 二、工作台新建交互
1. 新建按钮点击触发下拉弹窗，选项包含：对象类型、链接、动作
2. 权限过滤：下拉菜单仅展示当前登录用户**具备新建权限**的资源选项，无权限选项隐藏
3. 点击任一选项直接跳转对应独立创建页面，流程无缝衔接
4. 无新建权限用户隐藏全局【新建】按钮，无法触发新建操作

## 三、通用交互规则
1. 工作台首页支持全局名称模糊搜索，快速筛选智能体内所有对象类型
2. 支持快捷查看各类资源列表、智能体权限配置、内部数据修改调整
3. 菜单选中状态、hover高亮、页面跳转加载状态、权限隐藏显示逻辑统一遵循原型交互规范
