# 功能概述
对象类型列表用于展示智能体EDA内所有对象类型数据，支持分页展示、数据筛选、关键词检索、列表刷新、新建入口及详情查看能力，满足不同权限用户查询、管理对象类型的业务需求。

# 用户角色
- 普通业务用户
- 权限管理员
- 系统管理员
- 产品经理

# 功能步骤
1. 进入页面，默认分页加载全部对象类型数据
2. 顶部搜索框输入关键词，筛选匹配列表数据
3. 点击刷新按钮，重新拉取最新列表数据
4. 点击右上角新建按钮，跳转对象类型创建页面
5. 点击列表操作栏查看按钮，进入对应对象类型详情页

# 交互说明
1. 页面布局、表格样式、按钮位置、页面UI状态严格参照上方Figma设计稿与截图还原前端页面
2. 搜索框输入规则：限制1-50个字符，支持中英文、数字，支持ID、RID、名称检索
3. 搜索采用防抖处理，输入过程每秒触发一次搜索请求
4. 检索匹配优先级：精确匹配 > 前缀匹配 > 全字段模糊匹配，结果按最后修改时间降序排序
5. 搜索为空时默认展示全量数据，检索命中关键字自动高亮显示
6. 列表固定展示字段：对象类型图标、名称、状态、可见性、最后修改时间、操作列
7. 操作列默认仅展示**详情**按钮，根据用户权限开放对应操作权限
8. 需兼容页面加载中、无数据、搜索无结果等空状态UI样式
9. 分页、筛选、功能按钮禁用/启用状态统一对齐设计交互规范
