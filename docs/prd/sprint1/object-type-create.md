# 功能概述
用户通过新建入口进入分步创建向导，依次完成数据源选择、元数据填写、属性配置、动作配置，最终完成全新对象类型创建，生成完整对象类型及配套属性信息，满足业务自定义对象类型搭建需求。

# 用户角色
- 智能体管理员
- 拥有智能体修改权限用户
- 系统管理员
- 产品经理

# 功能步骤
1. 入口触发：Matrix工作台/对象类型列表页点击【新建】，进入创建向导首页
2. 第一步：选择数据源，选择新建数据集或选用已有数据集，完成填写后进入下一步
3. 第二步：完成对象类型元数据信息配置，校验通过进入下一步
4. 第三步：新增并配置对象属性，设置标题键、主键规则，满足条件后进入下一步
5. 第四步：按需配置对象动作类型，确认信息后点击完成，提交创建
6. 创建成功后自动返回对象类型列表页，展示最新创建数据

# 交互说明
- 全流程分步页面布局、表单样式、按钮排布、弹窗样式严格对齐上方Figma设计稿与截图还原
- 流程强校验：每一步**所有必填项填写完整**才可点击下一步，未填必填项置灰禁用下一步按钮
- 数据源配置规则
  1. 新建数据集：数据集名称必填，项目目录下唯一，仅支持字母、数字、下划线，首字符为字母，最长128字符；必须选择合规平台存储路径
  2. 已有数据集：仅支持目录内选择存量数据集，不可自定义编辑名称与路径
- 元数据表单规则
  1. 对象类型图标：仅从系统预设图标库选择，由底色+预设图标组合生成
  2. 对象类型名称：必填，组织空间内全局唯一，支持中英文、数字、短横线，最长64字符
  3. 英文名称：必填，全局唯一，仅英文、数字、短横线，最长64字符
  4. 描述：非必填，纯文本含标点，最大256字符
  5. 所在对象组：二期迭代实现，仅可选已存在分组，分组删除自动归为未分组
  6. 对象类型ID：系统默认生成，支持手动修改；仅小写字母、数字、短横线，首字符小写；已被业务引用后修改会造成依赖异常，前端增加修改风险提示
- 属性配置交互规则
  1. 对象类型**至少配置1条属性**，无属性无法发布对象类型
  2. 属性名称：当前对象内唯一，支持中英文、数字、下划线，最长64字符
  3. 属性类型：必填，默认string，可选string/int/float/boolean/datetime
  4. 字段关联：新建数据集可自定义字段名，已有数据集字段只读不可编辑
  5. 标题键：从已添加属性中单选指定，作为对象默认展示名称
  6. 主键配置：从已添加属性中单选指定；修改主键弹出确认弹窗，提示替换原有主键并二次确认
- 动作配置规则
  1. 动作非必填，可选创建、编辑、删除三类动作，选择动作后，出现配置可执行操作的用户/用户组字段，可以配置多个用户/用户组。
  2. 可跳过动作配置直接点击完成提交创建
- 权限交互：无智能体修改权限用户隐藏新建按钮，无法进入创建流程
- 页面通用交互：支持上一步返回修改表单，各表单实时字段格式校验、唯一性重名校验，错误文案前端实时提示
