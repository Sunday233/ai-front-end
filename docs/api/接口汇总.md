## 说明

- 来源 PRD：`docs/prd/workbench.md`、`docs/prd/object-type-list.md`、`docs/prd/object-type-create.md`。
- 当前后端未提供正式 `method/path`，实现中统一标记为“待后端确认”，并使用 `/mock/**` 路径承载前端还原与联调前验证。
- 所有页面请求统一通过 `src/services/client.ts` 的 `httpClient` 发起；页面、组件与 service 不写 mock 分支。
- Mock 只在 `src/services/mock.ts` 统一注册页面级 handler，后续接入真实接口时替换各 service 的 path/method 与字段映射即可。
